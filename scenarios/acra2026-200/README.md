# ACRA 2026 matched scenario bank

This directory contains 200 scenarios generated by
`scripts/generate_acra_scenarios.py`. The bank is not a headless result set.

- six controlled robots per scenario, each with a start and end goal;
- six moving patrol obstacles per scenario;
- source names: `random-s0-0000` through `random-s0-0199`;
- initial overlap audit: no robot–robot or robot–obstacle physical overlaps;
- runtime trigger status must be measured later by the headless evaluation;
  moving obstacles alone do not prove that an event trigger occurred.

Use this directory as the explicit `--scenario-bank` input for future matched
headless arms.
